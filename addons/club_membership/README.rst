Club Social - Membership
========================

Módulo base para la gestión administrativa de socios del
Club Social Petrolero Polanco sobre Odoo 18 Community.

Este módulo será responsable inicialmente de la gestión de:

* Socios y clientes.
* Beneficiarios.
* Estados del asociado.
* Estado legal.
* Kardex.
* Reglas institucionales principales.

Los módulos de certificados patrimoniales, contabilidad,
control de acceso y portal se desarrollarán de forma separada.
